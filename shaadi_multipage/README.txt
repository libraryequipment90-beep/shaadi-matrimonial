SHAADI.COM MULTI-PAGE UI PREVIEW

How to preview:
1. Extract this ZIP file to a folder.
2. Double-click index.html to open the homepage in Chrome or Edge.
3. Use the top navigation to open Home, Search, Success Stories, Services, Community and Help.
4. Login and Register Free are also separate pages.

This is a front-end UI prototype. Forms show demo messages and do not use a database, real authentication, payments or live member profiles. Images require an internet connection.
